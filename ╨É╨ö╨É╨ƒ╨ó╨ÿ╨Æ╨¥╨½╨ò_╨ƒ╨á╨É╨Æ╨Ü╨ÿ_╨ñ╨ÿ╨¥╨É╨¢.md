# CheFish — финальные адаптивные правки

- Четыре feature-секции сохраняют чередование на всех ширинах: овощи справа, соусы слева, тунец справа, сборка слева.
- Положение контента задаётся через CSS Grid (`justify-self`), а выравнивание текста — через `text-align`.
- Убраны конфликтующие сбросы `margin: 0` и единый левосторонний градиент в breakpoint 980px.
- Для правых секций градиент остаётся справа и на планшетах; описания выровнены к правой стороне.
- FRESH & TASTY: на экранах шириной 650px и меньше позиционируется справа сверху; на ширине до 360px отступы уменьшены симметрично.
- Существующий контент, изображения, маршруты и цены не изменены.

Проверки: `npm test` — 16/16; `npm run build` — успешно.

Локальный запуск: `npm run dev`. Для публикации использовать существующий GitHub Actions workflow.
