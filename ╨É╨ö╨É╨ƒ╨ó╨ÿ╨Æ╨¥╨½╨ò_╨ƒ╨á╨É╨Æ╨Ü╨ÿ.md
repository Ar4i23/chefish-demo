# Адаптивные правки CheFish

- Слова «ШАУРМА» и «КОТОРАЯ» имеют одинаковый размер шрифта.
- FRESH & TASTY: справа внизу при ширине более 650 px, справа вверху при 650 px и меньше.
- На мобильных экранах сохранено чередование правого и левого расположения текста в секциях истории.
- Увеличены интервалы между строками и словами в заголовке «ВКУС CHEFISH — В КАЖДОЙ ДЕТАЛИ».
- Фотографии, данные меню, корзина и роутинг не изменялись.

Проверка: `npm test` (16 тестов), `npm run build` (успешно).
Запуск: `npm run dev` из папки `chefish-demo`.
