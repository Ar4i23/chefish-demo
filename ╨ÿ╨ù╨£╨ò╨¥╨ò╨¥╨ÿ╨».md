Комбо «Курица в пите, фри и айран» оставлено без изменения: необходимо подтвердить у заказчика, существует ли оно в реальном меню. Прямые переходы на вложенные URL требуют корректной настройки статического хостинга.

## Запуск

`npm run dev` — локальная разработка; `npm test` — тесты; `npm run build` — подготовка папки `dist` для публикации. React не используется. В браузере работает обычный HTML/CSS/JS.
